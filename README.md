# swagglar-packages

Unmodified upstream [Scalar](https://github.com/scalar/scalar) packages (MIT licensed), vendored here as a stable base for the private [Swagglar](https://github.com/abetoluwani/swagglar) product.

Snapshot taken from `scalar/scalar@65731dfff7eb261a93241af7f150a42c0ed00a2a`. These packages are not modified here — this repo exists so the private product repo does not depend on Scalar's own npm registry availability or versioning, and can pull upstream fixes deliberately via this repo's own history.

See the upstream project for documentation: https://github.com/scalar/scalar
